# Security policy

## Supported versions

Only the latest release of each widget is supported. Please update before reporting.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately with [GitHub's private vulnerability reporting](https://github.com/danewrx/plasma-widgets/security/advisories/new). Include:

- which widget and version is affected
- your Plasma version
- steps to reproduce, and what you expected to happen

I'll reply as soon as I can, and I'll credit you in the fix unless you'd rather I didn't.

## Scope

These widgets run local commands (for example the `mullvad` CLI) and read their output. Issues in those tools, in Plasma itself or in the Mullvad app should be reported to their own projects.
